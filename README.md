# 🍏 Студенческая столовая «Под яблоком Ньютона» (НГТУ)
> Современное интерактивное электронное SPA-меню с персональным ИИ-нутрициологом **Gemini 3.8 Flash**, расчетом КБЖУ подноса и поддержкой **Supabase**.

Разработано специально для студентов и преподавателей **Новосибирского государственного технического университета (НГТУ • NETI)** в стилистике инженерного минимализма (Apple, Notion, Яндекс Лавка).

---

## ⚡ Особенности и функционал

1. **Дизайн и эстетика:**
   - Высококонтрастная палитра: глубокий графит (`#0F172A`), чистый белый, мягкий фон карточек (`#F5F5F7`) и акцентный цвет **«Кислотное яблоко» (`#84CC16`)**.
   - Атмосфера НГТУ: формулы гравитации и кинетической энергии ($F = G\frac{m_1 m_2}{r^2}$, $E = mc^2$), мягкие скругления `border-radius: 20px`, микро-анимации и праздничное конфетти.
   - Полная адаптивность: удобное отображение на смартфонах с плавающей нижней панелью подноса и на экранах ноутбуков.

2. **База 10 фирменных блюд:**
   - Борщ «Сибирский» с говядиной и сметаной
   - Куриный бульон с домашней лапшой и яйцом
   - Котлета по-киевски с маслом и зеленью
   - Гуляш из говядины с подливой
   - Филе минтая в сырной корочке
   - Картофельное пюре на сливочном масле
   - Гречка рассыпчатая с луком и морковью
   - Салат «Цезарь по-студенчески» с курицей и сухариками
   - Салат витаминный из свежей капусты с яблоком и морковью
   - Шарлотка «Яблоко Ньютона» с корицей + Ягодный морс

3. **Интерактивный «Поднос студента» (Корзина & Калькулятор):**
   - Автоматический пересчет итоговой стоимости в рублях.
   - Мгновенный суммарный расчет калорийности и баланса **Белков, Жиров и Углеводов (БЖУ)** всего обеда с цветной визуализацией соотношения макронутриентов.
   - Возможность скопировать состав обеда в буфер обмена для отправки одногруппникам.

4. **ИИ-нутрициолог «Ньютон AI» (Powered by Gemini 3.8 Flash):**
   - Умный конструктор обеда по свободному текстовому запросу или быстрым пресетам:
     - *«💪 Максимум белка до 300 ₽»*
     - *«🍏 Легкий обед до 450 ккал»*
     - *«⚡ Сытный комбо для пар до 250 ₽»*
   - Интеллектуальный **Smart Fallback**: в случае недоступности внешнего API или ограничений сети мгновенно включается встроенный локальный алгоритмический движок, сохраняя полную работоспособность приложения и генерируя остроумные комментарии студента НГТУ.
   - Кнопка **«Закинуть весь сет на поднос в 1 клик»** с анимацией салюта.

## 🗄️ Подключение к Supabase за 2 простых шага

Приложение спроектировано с концепцией **Zero-Config Fallback**: если ключи Supabase не заданы, оно сразу же работает на встроенном быстром массиве блюд.

Чтобы переключить меню на живую базу данных Supabase:

### Шаг 1. Создайте таблицу и заполните данные
1. Перейдите в ваш проект на [supabase.com](https://supabase.com).
2. Откройте раздел **SQL Editor** в левом меню.
3. Скопируйте всё содержимое готового файла [`supabase_setup.sql`](./supabase_setup.sql) из корня этого репозитория, вставьте в редактор и нажмите кнопку **Run**.
*(Таблица `dishes` будет создана, включен RLS на публичное чтение и добавлены 10 стартовых блюд).*

### Шаг 2. Подключите ключи к приложению
Выберите любой удобный способ:
- **Способ А (Прямо в интерфейсе):** Нажмите иконку шестерёнки ⚙️ в шапке сайта, вставьте ваш `Project URL` и `Anon Key` и нажмите «Проверить связь» / «Сохранить».
- **Способ Б (Через .env):** Создайте файл `.env` в корне проекта на основе `.env.example`:
  ```bash
  VITE_SUPABASE_URL=https://your-project-id.supabase.co
  VITE_SUPABASE_ANON_KEY=your-anon-key-here
  ```

## 🚀 Локальный запуск и разработка

```bash
# 1. Клонирование репозитория
git clone https://github.com/your-username/newton-apple-nstu-menu.git
cd newton-apple-nstu-menu

# 2. Установка зависимостей
npm install

# 3. Запуск сервера разработки
npm run dev

# 4. Сборка продакшн-бандла
npm run build
```
